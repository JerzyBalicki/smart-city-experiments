# Smart City Experiments

Statyczna witryna GitHub Pages. Strona główna kataloguje eksperymenty, a pierwszy projekt znajduje się w katalogu `experiments/intelligent-transport/`.

## Publikacja

Umieść zawartość tego katalogu w głównym katalogu repozytorium. W GitHub wybierz **Settings → Pages → Deploy from a branch**, a następnie gałąź **main** i katalog **/(root)**. Adres wdrożenia pojawi się w ustawieniach Pages.

## Kolejny eksperyment

Utwórz katalog `experiments/nazwa-eksperymentu/` z własnym `index.html` i plikami. Użyj wspólnego arkusza `../../style.css`. Na stronie głównej skopiuj kartę bieżącego eksperymentu i zmień tytuł, adres oraz opis.
